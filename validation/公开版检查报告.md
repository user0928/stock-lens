# 公开版检查报告

本轮检查对象为股东观察应用整体，不涉及 Windows 系统配置。以已有第二版真实数据与核验记录为基础。

## 修复与优化

- 桌面数据/资讯并排，手机顺序阅读；统一字体、色彩、字号、控件间距与图例。
- 搜索支持组合框与键盘选择、Ctrl K、使用指南；明细可导出CSV，资讯标题本地筛选和分段显示。
- 刷新与短时连接失败保留当前数据/选点，切换股票不显示旧股票数据；旧采集状态缺口在新结果成功时清除。
- 匿名浏览器后台订阅独立维护，互不覆盖；保留旧个人库关注与全部股东数据，增量新增订阅表和价格/新闻索引。
- 来源状态收起重复提示，同时保留失败、缓存、部分数据、备用来源与原站入口。
- 限制并发与队列大小、API请求预算；增加搜索缓存、内容类型/引用策略/框架限制响应头。
- 前端按需载入图表并分包，业务入口约28KB（gzip约11KB）；总资源仍包含React和ECharts，不能将入口大小解释为全部加载量。
- 准备MIT代码许可、Windows/macOS/Linux运行说明、Docker/Compose、GitHub Actions自动测试。

- 新股票清除旧卡片、资讯标题筛选、帮助弹窗、搜索快捷键通过。

- 本机Docker CLI存在，但Docker引擎未运行；容器实测由公开仓库CI完成，结果在发布核验中补充。
- 未进行大规模负载测试，限流/任务去重仅支持单实例；本轮未部署在线查询站点。
- 原有12个统计日价格跨来源一致与18条原文记录仍见第二版报告；本轮没有重新声称完成新的全源历史核验。
